## Overview

Honeypot is a Medium Coding challenge served through HTB's web coding harness (a Monaco editor that POSTs your source to `/run` and grades it against hidden tests). It's a rooted-tree problem: contain a breach by placing a single firewall while keeping a honeypot node reachable.

## The problem

You get a tree of `N` nodes with `N-1` edges (`"A - B"` per line), rooted at the compromised node **1**, plus a honeypot node **H**. You place **one firewall** on a single edge. Cutting the edge to a child removes that child's entire subtree from the root's reach — but the honeypot must remain reachable. Report the **minimum** number of nodes still exposed.

Cutting the edge above node `c` removes `subtree(c)`, which is allowed only if that subtree does **not** contain `H`. A subtree contains `H` exactly when its root is `H` or an ancestor of `H`. So:

```
exposed_min = N - max{ size(subtree(c)) : c ≠ root, c ∉ {H and its ancestors} }
```

If no such `c` exists, no firewall can be placed without isolating `H`, so the answer is `N`.

For the sample (`N=7`, root 1, `H=5`), the largest cuttable subtree not containing 5 is node 6's `{6,7}` (size 2), giving `exposed = 7 − 2 = 5`.

## Solution

```python
import sys
from collections import defaultdict
def main():
    it = iter(sys.stdin.read().split('\n'))
    N = int(next(it).strip())
    adj = defaultdict(list)
    for _ in range(N-1):
        a, b = next(it).strip().replace(' ', '').split('-')
        a, b = int(a), int(b); adj[a].append(b); adj[b].append(a)
    H = int(next(it).strip())
    parent = {1: 0}; order = []; seen = {1}; st = [1]
    while st:                                   # iterative DFS (no recursion limit)
        u = st.pop(); order.append(u)
        for v in adj[u]:
            if v not in seen: seen.add(v); parent[v] = u; st.append(v)
    size = {u: 1 for u in order}
    for u in reversed(order):                   # post-order subtree sizes
        if parent[u] != 0: size[parent[u]] += size[u]
    anc = set(); x = H
    while x != 0: anc.add(x); x = parent.get(x, 0)   # H + ancestors
    best = max((size[u] for u in order if u != 1 and u not in anc), default=0)
    print(N - best)
main()
```

## Why it worked

Modeling "one firewall on one edge" as "delete one subtree" reduces the whole task to subtree sizes on a rooted tree. The honeypot constraint just excludes the subtrees that contain `H` — that is, `H` and its ancestors. Iterative DFS keeps it safe on large inputs.
