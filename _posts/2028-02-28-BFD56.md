## Overview

BFD56 is a Medium crypto challenge. The name and the hint ("At least Delastelle didn't have to worry about bit flipping") point straight at the Bifid cipher, invented by Félix Delastelle. The twist is a CBC-style masking layer bolted on top — which, as we'll see, adds no real security, because the value doing the chaining is public.

## The cipher

The alphabet is the classic 25-letter Polybius set `ABCDEFGHIKLMNOPQRSTUVWXYZ` (no J). A secret key defines a 5×5 square, mapping each letter to `(row, col)` coordinates and back. Encryption works in blocks of 8 (the IV length):

1. **Mask.** Each plaintext block is Vigenère-**added** (mod 25) to the previous *ciphertext* block — CBC mode, but with modular addition instead of XOR. The IV masks the first block.
2. **Bifid.** The masked block is fractionated: write the rows of all 8 letters, then the columns, then read that sequence in pairs back through the square.

The output is `(iv, ciphertext)`.

## The key insight

At first glance this looks like it needs both the key square and some way through the chaining. But the mask uses the *previous ciphertext block* — which we already have. So decryption is:

```
plaintext_block = unmask( bifid_decrypt(cipher_block, key), previous_cipher_block )
```

Everything except `key` is known. The masking contributes nothing to the difficulty — decryption is a pure function of the 25-character key square. This is the general lesson: wrapping a classical cipher in "CBC mode" whose chaining value is public ciphertext buys no security.

So the whole challenge reduces to recovering a 25-letter key from ciphertext — exactly a standard Bifid break, solvable by climbing an English-language fitness function.

## Solution

Write a `decrypt(key)` that inverts the Bifid step (`res[2k], res[2k+1] = coords(cipher[k])`; `masked[i] = square[res[i], res[i+L]]`) and then unmasks with the previous ciphertext block. **Round-trip-test it against the provided `encrypt` first** — a subtle inversion bug would cap the search at a wrong optimum. Score candidate plaintexts with quadgram log-probabilities (practicalcryptography's `english_quadgrams.txt`) and optimize the key.

Plain greedy hill-climbing (accept only improving 2-letter swaps) plateaus in a local optimum — you get tantalizing fragments ("THAT", "TIME", "SELF") in otherwise garbled text. **Simulated annealing** escapes it: the same 2-swap move, but accept a worse score with probability `exp((new − old) / T)`, cooling `T` from ~20 toward 0, across ~40 random restarts.

Create `solve.py`:

```python
import random, math
ALPH = "ABCDEFGHIKLMNOPQRSTUVWXYZ"
iv, CT = eval(open('files/ciphertext.txt').read()); BL = len(iv)
IA = {c: i for i, c in enumerate(ALPH)}

Q = {}; tot = 0
for line in open('english_quadgrams.txt'):
    k, c = line.split(); Q[k] = int(c); tot += int(c)
FLOOR = math.log10(0.01 / tot); LOG = {k: math.log10(v / tot) for k, v in Q.items()}
score = lambda t: sum(LOG.get(t[i:i+4], FLOOR) for i in range(len(t)-3))

blocks = [CT[i:i+BL] for i in range(0, len(CT), BL)]
def unmask(msg, mask):
    m = mask * (len(msg)//len(mask) + 1)
    return "".join(ALPH[(IA[i]-IA[j]) % 25] for i, j in zip(msg, m))

def decrypt(key):
    idx = {c: (i//5, i%5) for i, c in enumerate(key)}
    sq  = {(i//5, i%5): c for i, c in enumerate(key)}
    out, cmask = [], iv
    for b in blocks:
        L = len(b); res = [0]*(2*L)
        for k, ch in enumerate(b):
            res[2*k], res[2*k+1] = idx[ch]
        masked = "".join(sq[(res[i], res[i+L])] for i in range(L))
        out.append(unmask(masked, cmask)); cmask = b
    return "".join(out)

def anneal():
    key = list(ALPH); random.shuffle(key)
    cur = score(decrypt(key)); best, bkey = cur, key[:]
    for s in range(9000):
        T = max(0.01, 20*(1 - s/9000))
        a, b = random.sample(range(25), 2); key[a], key[b] = key[b], key[a]
        sc = score(decrypt(key))
        if sc > cur or random.random() < math.exp((sc - cur)/T):
            cur = sc
            if sc > best: best, bkey = sc, key[:]
        else:
            key[a], key[b] = key[b], key[a]
    return best, ''.join(bkey)

gb, gk = -1e9, None
for _ in range(40):
    b, k = anneal()
    if b > gb: gb, gk = b, k
print(decrypt(gk))
```

The recovered plaintext is a full paragraph that ends by literally stating the flag:

> ...THEY DESERVE AN HTB FLAG WHICH IS THESE WORDS SEPARATED BY UNDERSCORES: ANYTHING IS A BLOCK CIPHER IF YOU TRY HARD ENOUGH

```
HTB{...}
```

## Why it worked

The masking is CBC with a public chaining value, so it never enters the key search — decryption depends only on the 25-letter square. A 25-symbol key is far too small for classical fractionation to resist a quadgram-guided search, and simulated annealing reliably beats the local optima that trap plain hill-climbing.

## Fix / defense

Classical ciphers and their "modes" provide no confidentiality against a quadgram hill-climb — use a real authenticated cipher (AES-GCM, ChaCha20-Poly1305) with a proper key. And "ECB is weak, so I added CBC" only helps when the construction underneath is a secure block cipher and the IV/chaining is unpredictable to the attacker; layering modes over a broken primitive changes nothing.
